# AI Vision Skills catalog

Each directory contains an independently installable Skill. Start with its
`SKILL.md` and follow the bundled references and scripts for your workflow.

| Skill | When to use it |
| --- | --- |
| [aivision-deploy](aivision-deploy/SKILL.md) | Set up or upgrade a deployment and onboard its first user. |
| [aivision-quickstart](aivision-quickstart/SKILL.md) | Start from an existing platform and generate and inspect your first traces. |
| [aivision-trace](aivision-trace/SKILL.md) | Query, inspect, or export traces from an existing workload. |
| [aivision-metric](aivision-metric/SKILL.md) | Query trace and usage metrics and interpret coverage. |

See the [installation guide](../README.md#install-with-npx-skills) for
`npx skills` and manual installation. If an installed copy still tracks an
older source repository, reinstall from this catalog using the same scope and
agent. Review local changes before replacing a copy. For product downloads and
maintenance ownership, see [Distribution](../docs/distribution.md).
